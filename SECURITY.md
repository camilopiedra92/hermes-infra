# Security policy

This repository describes one private server. It holds no secret, and the server accepts no public inbound connection.

* Report a vulnerability in this repository, or a mistake that exposes something, with GitHub's **private vulnerability
  reporting** (the Security tab of this repository). Do not open a public issue for it.
* Issues and pull requests from outside are not accepted. This is a personal infrastructure repository, published so that its
  decisions and checks can be read.
* Nothing here is an offer to reuse the code. No licence is granted.
